# muse-panels

我用 Muse 搭建的面板（Web Artifact）源码库 — 控制面代码统一在这里维护和
版本管理，每个面板一个子目录，数据面严格分离（见下文）。目前收录两个面板：

- **`portfolio-board/`（投资组合看板）**：多账户持仓总览。账户页签（全局 / 单账户），
  全局视图自动合并同一只股票的跨账户持仓（股数相加、成本加权平均）；顶部行情条
  （标普500、纳指100、现货黄金、上海黄金 Au99.99 元/克）；标准列表与可排序表格
  两种持仓视图；集中度分析（主题分布、前五大持仓、浮亏来源）；隐私模式（一键
  遮罩全部金额、只留百分比）；盘前 / 盘后延长时段价格与异动提示、相对收盘口径
  的实时估算总值。红涨绿跌。
- **`history-board/`（投资历史看板）**：只记录账户整体总值的时间序列（每日快照：
  总值、证券、现金、未实现盈亏、当日涨跌、美元汇率、人民币总值、标普 / 纳指收盘），
  提供总值曲线、每日涨跌、证券 / 现金结构、与指数的归一化对比和每日明细表。
  同样带隐私模式。

## 控制面 / 数据面分离

本仓库**只包含控制面代码**（前端、服务端动作、数据库结构迁移），**不包含任何
真实持仓数据**：

- 真实数据存放在运行时的 `app.db` 中（已被 `.gitignore` 排除，永远不会入库）。
- 代码里自带的种子是**虚构示例数据**：示例持仓（AAPL / MSFT / JPM / VOO 的整数
  股数与整百成本）、示例账户「券商A / 券商B」、示例首日快照（总值 $10,000）。
  换成你自己的数据即可使用：面板内可逐只添加 / 编辑持仓与现金，账户也可以增删。

## 口径约定

- 官方口径一律采用**美股常规时段收盘价**：总值、市值、浮盈亏、占比、每日快照
  都按收盘价计算。
- 盘前 / 盘后价格只作为标注与「实时估算」参考，不进入官方口径；夜盘（美东
  20:00–04:00）没有公开实时数据源，显示盘后最后成交价。
- 历史看板中 `source = "manual"` 的记录受保护，不会被自动同步覆盖。

## 运行环境说明

这套代码是为 Muse 的托管 Web Artifact 运行时（TypeScript space：
`client/` React 前端 + `server/src/actions.ts` 服务端动作 + `drizzle/` 迁移）
编写的。在自己的 Muse 中按同样的 space 结构导入两个目录、分别构建即可运行；
行情来自公开数据源（Nasdaq 公开接口等），汇率来自 open.er-api.com /
frankfurter.app，均无需 API Key。迁移到其他运行时需要自行适配其数据与动作层。
