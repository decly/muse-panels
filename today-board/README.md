# today-board（看板 · 今日页）

静态晨报页（slug：kan-ban-jin-ri-ye）：每天早晨生成一次、全天不变，
只呈现常规时段收盘口径。

## 主要功能

- 单列手机优先布局：北京日期 + 一句话总览；账户总览（全局/各账户，
  收盘口径，带隐私开关）；昨夜动向；今日事件；现货黄金 + 上海黄金；
  其他资产一行（10 年美债 / 原油 / 美元指数）与周一技术行（未推送
  时整块隐藏）。
- 昨夜动向由页面端从推送的全量动向集合中确定性选取：涨幅前五、
  跌幅前五，以及全部 |涨跌| ≥ 5% 的个股。
- 纯静态：页面无手动刷新按钮，时间标注为「生成于」。

## 服务端动作

- `getToday`：读取页面全部区块数据。
- `pushDigest`：助手/定时任务的推送通道，按区块写入总览、账户、
  动向、其他资产、技术行（字段可选，只覆盖出现的区块）。
- `refreshToday`：仅刷新金价与指数收盘缓存（每日 06:45 定时执行）。
- `seedEvents` / `upsertEvent` / `deleteEvent`：今日事件的种子
  与维护。

## 数据说明

页面内容属运行时数据（晨报推送的账户总览、动向与事件），只存在
线上运行时的 app.db，不入库；仓库版事件种子为虚构示例。代码中
账户标识为中性 id（broker-a / broker-b），显示标签随推送数据下发。

## 维护注意事项

- 只收常规收盘口径内容：盘后/夜盘异动不进今日页（归全天动态面板）。
- 内容来源只有两路：每日 06:30 晨报任务的 `pushDigest` 与 06:45 的
  `refreshToday`（仅金价/指数）；周末无市的简版晨报不推送。
