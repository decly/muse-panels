# cn-portfolio-board（看板 · A股持仓）

人民币 A 股持仓面板（slug：kan-ban-agu-chi-cang）：单个中国证券账户的
持仓明细与板内历史视图，结构沿用美股持仓面板、去掉美股特有功能，
空数据起步（首期持仓由助手按券商截图录入）。

## 主要功能

- 总览、持仓明细、集中度、交易流水与板内历史（每日快照与总值曲线）
  合一：历史不再拆独立面板，快照就存在本板内。
- 持仓以 ETF / 基金 / 个股三类记录（代码 6 位数字，市场前缀按首位
  数字推导沪 / 深 secid）；现金单独维护，计价货币人民币。
- 基准条：上证指数、深证成指、沪深 300、中证 A500、创业板指。
- 交易流水台账（只记账，不驱动持仓与快照）：摊薄成本法重放、按
  交易日粒度结算已清仓损益，口径与美股持仓面板一致。
- 隐私模式遮罩具体金额，百分比与公开价格保持可见；涨跌红涨绿跌。

## 服务端动作

- `getBoard`：读取页面全部数据（持仓、现金、报价、基准、快照、
  流水）。
- `refreshQuotes`：手动刷新实时报价（东方财富公开接口）。
- `refreshCloseSnapshot`：收盘刷新 + 写入当日快照；每工作日 15:10
  由定时任务 `kan-ban-agu-close-refresh` 调用，节假日按报价日期
  自动跳过、不写快照。
- `addHolding` / `updateHolding` / `removeHolding` / `updateCash`：
  持仓与现金维护。
- `getTrades` / `addTrade` / `updateTrade` / `deleteTrade`：交易
  流水台账。
- `exportData` / `importData`：个人数据导出 / 导入（与 muse-data
  每日备份对接）。

## 数据说明

运行时数据（持仓、现金、快照、流水）只存在线上运行时的 app.db，
不入库；本板空数据起步，仓库版不含任何种子持仓。

## 维护注意事项

- 官方口径一律采用 A 股收盘价：总值、市值、浮盈亏、占比与每日
  快照都按收盘价计算；盘中实时价只供手动刷新查看，不写入快照。
- 东方财富 push2 接口偶发 502：代码内多主机按序重试，全部失败时
  保留已存报价，不以空值覆盖。
- 不做消息面定时跟踪；周维度汇总并入周六持仓周汇总的 A 股段，
  不另设任务。
