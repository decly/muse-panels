# stream-board（看板 · 全天动态）

24 小时全资产事件流面板（slug：kan-ban-quan-tian-dong-tai）：倒序
事件流（最新在上、按天分组），覆盖盘前 / 盘中 / 盘后 / 夜盘全时段。

## 主要功能

- 七类彩色标签：股票 / 财报 / 黄金 / 原油 / 美债 / 美元 / 宏观；
  涉及持仓代码的事件高亮。
- 顶部实时行情条：纳指100期货、标普500期货、现货黄金、布伦特
  原油（BZ=F）、美元指数（DXY）；价格除原油与 DXY（两位小数）外
  取整；每 30 分钟自刷新。
- 板顶「近期节点」区（2026-11-11 新增）：行情条下方、类别筛选器
  上方，仅有节点时显示；按日期分组，每行日期（M月d日 周X）· 时
  间 · 事件描述 · 涉及持仓代码（下划线高亮）。
- 事件卡五段式：时间 + 标签 + 标题、异动明细表（movers：代码 /
  价格 / 涨跌幅）、说明、关键数字（keyNumbers，自动换行）、简要
  解读（impact，≤120 字）。
- 事件说明（note）上限 1000 字（2026-11-11 由 500 放宽）：写全信
  息口径——驱动 + 关键细节 + 来源，2–4 句，不裁剪为一句。
- 事件正文中带符号的 ▲/▼ 百分比与 bp 数字自动按红涨绿跌着色，
  无符号数字不上色。
- 事件保留 7 天，超期自动清理。

## 服务端动作

- `getStream`：读取事件流、行情条与近期节点（nodes 按日期/时间升序）。
- `refreshStrip`：刷新行情条五格报价。
- `appendEvent`：追加一条事件（分类/标题/说明必填；keyNumbers /
  tickers / movers / impact 可选；note 上限 1000 字）。
- `updateEvent`：按 id 修订已有事件。
- `setUpcomingNodes`：整体替换板顶近期节点列表（传入数组即为最新
  全量；空数组清空），返回写入条数。

## 数据说明

事件与行情均为公开市场数据，运行时生成、只存线上 app.db，不入库；
本面板不含任何账户金额，无隐私开关。

## 维护注意事项

- 事件由各监测流程核实后追加：持仓异动、黄金异动、原油/美元/
  美债阈值监测、机构观点变化、每日晨报补记（上一交易日财报结果
  + 重大新闻，合计 ≤ 5 条）、每日 21:00 盘前总览。
- 写入口径（2026-11-11 pc 定「全套补全」）：事件写全信息——note
  写完整说明（驱动 + 关键细节 + 来源，2–4 句），复核排除的标的
  在 note 末尾附注、不进 movers；晨报补记双价并列——已实时追加
  过的同一事件用 updateEvent 补第二价（movers 价格写「提醒时
  $X / 收盘 $Y」），原始提醒价一律保留、不覆盖。
- 近期节点由每日 06:30 晨报的「近期注意」表格全量推送维护
  （setUpcomingNodes，整体替换；周末/假期简版不推送，保留板上
  已有节点）；节点只推未来 7 天内，按日期排序。
- 行情条原油口径为布伦特（BZ=F）；晨报的其他资产行仍用 WTI，
  两处口径独立，勿混改。
