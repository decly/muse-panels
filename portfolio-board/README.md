# portfolio-board（看板 · 投资组合）

多账户美股持仓总览面板（slug：jia-xin-chi-cang-kan-ban）。

## 主要功能

- 账户页签：全局 / 各单账户。全局视图把同一只股票的跨账户持仓合并
  （股数相加、成本加权平均、展开看分账户明细），且只读、不可编辑。
- 顶部行情条：11 个基准（标普500、纳指100、纳指综合、上证指数、
  沪深300、中证A500、恒生科技、日经225、越南胡志明、现货黄金、
  上海黄金），可折叠、选择持久化；「距高点」按三年高点计算（历史
  高点仅在数据层保留、只上滚），价格显示整数。
- 持仓视图：标准列表与可排序表格（冻结首列与表头）两种；持仓明细
  置于集中度/结构分析之上；总览含总账户值（人民币换算附汇率）。
- 延长时段层：盘前/盘后/夜盘价格分时段三槽保存、互不覆盖；±3%
  异动行徽标与提示条；非盘中时段显示「实时估算」总值行。
- 隐私模式：遮罩总账户值、证券市值、现金、人民币总值、单只市值/
  股数与当日涨跌额；涨跌百分比、公开股价与成本价列不遮罩。
- 补录后自动重算：新增/修改/删除持仓或更新现金后，自动按「当前
  持仓 × 常规收盘价」重算该账户最新快照（截图来源行跳过保护），
  重算失败不回滚持仓修改本身。
- 刷新按钮下方显示本批报价的抓取时间（北京时间）。

## 服务端动作

- `getPortfolio`：读取面板全部数据（账户、持仓、快照、行情）。
- `refreshQuotes` / `refreshExtendedQuotes`：刷新常规时段报价 /
  延长时段价格（三槽保存）。
- `addHolding` / `updateHolding` / `removeHolding` / `updateCash`：
  持仓与现金维护，成功后触发最新快照自动重算。
- `seedHoldings` / `seedDailySnapshot`：写入虚构示例种子。
- `recalcDailySnapshot` / `recalcLatestSnapshots`：按收盘口径重算快照。
- `exportPersonalData` / `importPersonalData`：个人数据导出/导入
  （格式 v2，自描述信封 + 校验和）。

## 数据说明

个人数据（账户、持仓、现金余额、每日快照）只存在线上运行时的
app.db，永不入库；由私有库 muse-data 每日 06:50 备份（机制见根
README）。仓库内种子为虚构示例：示例持仓（AAPL / MSFT / JPM / VOO
的整数股数与整百成本）、示例账户「券商A / 券商B」。

## 维护注意事项

- 官方口径只认常规时段收盘价；延长价绝不写入快照与官方总值。
- 红涨绿跌全局统一；本文件与全库 README 均为中文。
