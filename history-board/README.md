# history-board（看板 · 投资历史）

账户整体总值的每日快照面板（slug：zhang-hu-li-shi-kan-ban）。只记
账户层面的总数字，**不存任何个股数据**。

## 主要功能

- 每日快照：总值、证券市值、现金、未实现盈亏、当日涨跌、美元汇率、
  人民币总值、标普/纳指收盘；以「日期 + 账户」为复合键，多账户
  各存一行。
- 全局视图：按日期汇总各账户（只汇总当日有记录的账户）；总值曲线、
  每日涨跌、证券/现金结构、与指数的归一化对比、每日明细表。
- 隐私模式与主看板同口径。
- 新鲜度自检：每日备份任务核对最新快照日期与最近美股交易日，
  滞后 ≥ 2 个交易日才报告（避开美股假日误报）。

## 服务端动作

- `getHistory`：读取全部快照与汇总视图数据。
- `recordSnapshot` / `deleteSnapshot`：写入 / 删除一条快照。
- `snapshotStatus`：最新快照日期等状态查询。
- `seedDemoRecord`：写入虚构示例记录。
- `exportPersonalData` / `importPersonalData`：个人数据导出/导入
  （格式 v2，自描述信封 + 校验和）。

## 数据说明

快照是个人数据，只存在线上运行时的 app.db，永不入库；由私有库
muse-data 每日 06:50 与主看板一并备份。同步来源有三路：主看板
每次更新持仓/现金后助手同轮同步、每日 06:40 定时同步兜底、
主看板快照自动重算顺带回写。

## 维护注意事项

- 截图来源（`source = "screenshot"`）的历史记录受保护，不被自动
  同步或重算覆盖。
- 本看板只接收账户总值层面的数字，禁止写入个股持仓明细。
